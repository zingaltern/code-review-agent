# ADR-0004 双验证者投票降级为 M3 数据门禁增量

- 状态：accepted（补录历史决策，素材自 01§8 修订记录，2026-10-25）
- 背景：M2 做不到验证者异构，"N 个高相关性投票者等价于 1 个"（01§8 首轮缺陷②⑧；03§2）——同构投票是虚假独立性。
- 决策：M2 单强模型验证者 + Judge 仲裁 + 拒真抽查保险丝；M3 双异构投票由数据门禁开启（拒真池样本 ≥20 且推翻率 ≥10%，或处置样本 ≥30 且精确率 <80%，03§4.3）。
- 理由：投票的统计收益依赖验证者错误去相关；样本量不足时在噪声内掷硬币决定头号特性去留是错的。
- 替代方案：M2 即上双验证者（同构投票空转）。
- 后果：`require-distinct-model-family` 违例拒绝启动（05§5）；头号特性去留由数据决定。
