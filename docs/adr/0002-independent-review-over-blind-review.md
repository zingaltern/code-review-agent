# ADR-0002 放弃"盲评"，改为独立复核 + 反锚定质控信号

- 状态：accepted（补录历史决策，素材自 01§8 修订记录，2026-10-25）
- 背景：finding 的 description/failure_mode 就是发现者的完整论证，"盲"是装饰（01§8 首轮缺陷③）；而引用新颖性硬校验会系统性拒真（二轮缺陷④）。
- 决策：verifier 看完整论证但必须独立重建证据链——自己定位行号 + 用自己的话重述失败模式（03§4.2）；新颖性校验降级为 `anti_anchor_check` 质控信号，FAIL 不阻断晋升（v1.2）。
- 理由：引用新颖性 ≠ 独立验证；单行证据类真缺陷的正确复述必然与原文高度重叠，硬校验要么压召回、要么退化为可绕过的新颖性游戏。
- 替代方案：剥离论证的真盲评；纯证伪指令（保留给 M3 V2 做指令差异化）。
- 后果：FAIL 率进周报预警（06§1.3 口径），基线漂移走 badcase 复盘而非自动拒真。
