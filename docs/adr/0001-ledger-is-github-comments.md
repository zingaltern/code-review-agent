# ADR-0001 状态账本 = GitHub 评论账本，而非本地库

- 状态：accepted（补录历史决策，素材自 01§8 修订记录，2026-10-25）
- 背景：v1.0 曾让"状态由 Actions 持有"，但 GitHub Actions 运行器用后即焚，run 之间不保留任何文件或数据库，幂等/收敛/处置机制在纯 CI 形态下必须有运行器之外的事实源（01§8 首轮缺陷①）。
- 决策：CI 形态以 bot 自身 PR 评论内嵌指纹与 DONE 标记为唯一事实源（02§5、05§1.3）；SQLite/PG 属本地/服务形态，统一走 `ReviewLedger` SPI（cra-store）。
- 理由：机制（幂等/收敛/处置）全部只依赖可重建状态，评论账本即事实源；接受放弃的状态（未发布候选、子代理中间输出）是调试便利而非机制依赖。
- 替代方案：常驻服务或数据库——M4 前不引入。
- 后果：解析五规则防污染（05§1.3）；跨 run trace 只留 artifact 90 天，接受。
